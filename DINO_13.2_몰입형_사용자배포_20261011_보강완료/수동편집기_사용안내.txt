DINO 13.2 몰입형 사용자버전 · 수동 편집기

구독 또는 관리자 인증을 마친 DINO의 롱폼 화면에서 [수동 편집기]를 누르세요.
별도 실행 파일을 직접 실행하면 편집할 수 없습니다. 수동 편집기는 롱폼 전용입니다.
1. 완성된 대본을 붙여넣거나 TXT로 불러오세요. 마침표로 문장을 나누며 소수점은 유지합니다.
2. 이미지·MP4를 드래그하거나 파일/폴더로 추가하세요. 001 → 002 → 003 번호로 정렬합니다.
   001.jpg, 001.png, 001.mp4와 점 없는 001jpg, 001png, 001mp4도 인식합니다.
3. 같은 번호의 MP4가 있으면 이미지 대신 영상을 사용합니다.
   MP4가 없는데 같은 번호의 이미지가 둘이거나 MP4가 둘이면 중복으로 표시합니다.
4. 문장 수·매칭 수·누락·중복, 문장별 파일과 미리보기를 확인하세요.
   번호 매칭은 자동입니다. 누락/중복은 시작을 막습니다.
   장면 내용이 문장의 의미에 맞는지는 미리보기로 직접 확인하세요.
5. 인월드 API 설정을 확인하고 [음성 생성 및 편집 시작]을 누르세요.
   내 PC 음성을 설치·등록한 경우 음성 방식에서 선택할 수도 있습니다.
   파일을 매칭하는 것만으로 유료 음성 호출이 시작되지 않습니다.
6. 음성 → 실제 낭독에 맞춘 자막 → 장면 연결 → MP4 순서로 진행합니다.

영상의 원래 소리는 사용하지 않으며, 짧은 영상은 해당 문장 낭독 길이에 맞춰 반복합니다.
대본을 다시 쓰거나 이미지를 새로 생성하지 않습니다.
영상 효과는 기본으로 켜져 있으며, 확대·축소와 부드러운 장면 전환을 함께 적용합니다.
느린 PC에서는 '효과 끄기 · 느린 PC용 빠른 편집'만 선택하세요. 움직임 없이 바로 전환합니다.
효과 선택은 자동 저장되어 다음 작업과 재실행에도 유지됩니다. 매번 설정할 필요가 없습니다.
기본 전환은 검정 암전 없이 두 장면이 겹치는 부드러운 교차 전환입니다.
자막 기본은 흰 글자+검정 배경이며, 배경 없는 검정 테두리도 선택할 수 있습니다.
720p 기본, 1080p 선택, 30fps 편집입니다.
매칭 로그는 완성 MP4와 같은 작업 폴더에 저장합니다.

내 목소리는 한 번 등록하면 재실행·완전 초기화 후에도 유지됩니다.
5~45초, 권장 10~20초. 조용한 곳에서 배경 음악 없이 본인 음성만 녹음하세요.
실제로 읽은 문장을 정확히 입력하고 등록한 목소리 듣기/시험 낭독으로 확인하세요.
목소리를 바꾸거나 저장된 녹음을 지웠을 때만 다시 등록합니다.

시험 범위·결과는 V12_기능시험결과.json, 전체 안내는 00_V12_먼저읽기.txt를 확인하세요.
