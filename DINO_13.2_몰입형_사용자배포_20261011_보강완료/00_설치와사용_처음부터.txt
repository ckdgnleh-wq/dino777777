--- 자세한 설치·업데이트 안내 ---

DINO 13.2 몰입형 처음 사용하는 분을 위한 설치와 사용 안내

1. 프로그램 실행과 인증
ZIP 전체를 새 폴더에 압축 해제하고 00_실행.cmd를 두 번 클릭하세요.
DINO.exe만 따로 옮기면 연결 파일이 없어 실행되지 않을 수 있습니다.
기존 DINO가 실행 중이면 먼저 종료하세요. 기존 구매·구독 계정으로 인증해야 제작 기능을 사용할 수 있습니다.
이미 인증한 PC는 기존 인증 정보를 계속 사용합니다. 화면에서 구독 남은 기간과 만료일을 확인하세요.
업데이트할 때 기존 작업·모델·등록한 목소리를 삭제하거나 완전 초기화할 필요가 없습니다.

2. 제작 방식을 고르세요
로컬: 내 PC에 설치한 이미지·음성 모델을 사용합니다. PC 조건과 설치 여부에 따라 사용 가능한 기능이 달라집니다.
Codex: 본인이 로그인한 PC앱의 Codex 대화에서 자료·대본·이미지 요청을 처리하고 DINO로 결과를 연결합니다.
API·Dropshot: 본인 계정과 API 키를 DINO 설정에 입력하고 선택한 제공사의 기능을 사용합니다.
세 방식은 계속 사용할 수 있습니다. 로컬·Codex 사용을 위해 무조건 API 키를 넣을 필요는 없습니다.
한 영상에서 방식을 섞으면 API로 선택한 단계에는 해당 제공사의 계정이 필요합니다.
API 키는 DINO 설정에 직접 입력하세요. 다른 사람의 키나 인증 정보가 배포본에 들어 있지 않습니다.

3. Codex PC앱 설치와 DINO 연결
이 안내는 PC앱을 사용하는 방법입니다. 사용자가 별도로 CLI 명령을 입력할 필요는 없습니다.
OpenAI 공식 설치 안내: https://learn.chatgpt.com/docs/quickstart
공식 PC앱 안내: https://learn.chatgpt.com/docs/app
공식 안내에서 Windows용 PC앱을 설치하고 본인 ChatGPT 계정으로 로그인하세요.
앱에서 Codex를 선택한 뒤, 압축을 푼 DINO 폴더를 작업할 프로젝트/폴더로 여세요.
앱 버전에 따라 제품 이름이나 메뉴가 다르게 표시될 수 있습니다. 이미 Codex PC앱을 사용 중이라면 그 앱에서 진행하세요.
DINO를 실행하고 구독 인증을 완료하세요.
DINO에서 Codex 제작 방식을 선택하고 활성화된 [Codex 요청문 복사]를 누르세요.
복사한 내용을 이 DINO 폴더를 연 Codex 대화에 붙여 넣어 보내세요.
Codex가 요청 파일을 읽고 결과를 등록하면 DINO 화면에 완료 개수와 진행 상태가 표시됩니다.
음성·영상까지 자동 옵션과 음성 설정이 준비되면 편집으로 이어집니다.
PC앱 설치만으로 DINO가 새 Codex 대화를 자동 시작하지는 않습니다. 작업 요청문을 대화에 보내야 합니다.
이미지 생성은 해당 Codex 대화에서 이미지 생성 기능을 사용할 수 있어야 합니다.

4. 로컬 설치가 어렵다면 Codex에 맡기세요
아래 문장을 그대로 복사해, DINO 폴더를 연 Codex PC앱 대화에 보내세요.
Codex가 PC 조건과 기존 설치부터 확인하고 가능한 기능을 설치·연결·시험하도록 요청하는 문장입니다.

----- 여기부터 복사 -----
이 폴더의 DINO 프로그램에서 로컬 이미지 생성과 로컬 음성을 사용하고 싶어.
내 PC의 Windows 버전, 그래픽카드와 VRAM, RAM, 디스크 여유 공간, 기존 DINO 로컬 설치를 먼저 확인해줘.
DINO의 로컬 기능 안내와 설치 목록을 읽고, 내 PC가 지원하는 기능만 DINO에 포함된 공식 설치 기능으로 설치해줘.
이미 설치된 모델, 정상 작동하는 실행 환경, 등록한 목소리, 인증 정보, 기존 작업은 보존하고 필요한 항목만 설치하거나 연결해줘.
설치 파일과 모델은 프로그램에서 지정한 공식 출처를 사용하고, API 키나 내 계정 정보는 채팅에 출력하지 마.
설치가 끝나면 DINO에서 연결 상태와 짧은 이미지·음성 시험 결과를 확인해줘.
PC 조건이 부족한 기능은 무리하게 설치하지 말고 어떤 조건이 부족한지 알려줘. 가능한 기능은 계속 진행해줘.
----- 여기까지 복사 -----

직접 설치하려면 DINO의 로컬 기능 화면에서 PC 조건과 설치 상태를 확인하고 필요한 이미지·음성 항목을 설치하세요.
로컬 모델은 용량이 크므로 다운로드 중 프로그램을 종료하지 마세요. 조건이 맞지 않는 경우 Codex 또는 API 방식을 선택할 수 있습니다.
본인 목소리가 필요한 경우 본인이 사용할 권한이 있는 음성으로 등록하고 시험하세요.

5. 한곳에서 설정하기 · 자동 제작과 수동 편집
왼쪽 [제작 설정 · 여기서 한 번에]에서 주제·대본, 이미지·레퍼런스, 음성, 편집, API 계정을 순서대로 설정하세요.
[주제·대본 / 이미지 / 음성 / 편집 / API 계정] 바로가기로 원하는 입력칸을 찾을 수 있습니다.
음성 만들기에서 [인월드 · Voice ID] 또는 [로컬 · 내 목소리]를 선택하세요.
인월드를 고르면 Basic Key와 Voice ID 입력칸이 나타나고, 로컬을 고르면 등록한 목소리를 사용합니다.
레퍼런스는 [레퍼런스 이미지 넣기]에서 사진 1장을 선택하세요. 현재 모델이 지원하지 않으면 이유가 표시됩니다.
오른쪽에는 제작 진행·Codex 요청문·대본·완성 파일이 표시됩니다. 좁은 화면에서는 설정과 결과가 위아래로 이어집니다.
자동 제작: 주제 또는 대본 입력 → 각 단계의 제작 방식 선택 → 전체 제작 → 결과 확인 → 다운로드.
수동 편집: 롱폼 화면에서 수동 편집기를 열고 대본과 이미지·영상 파일을 넣으세요.
번호가 같은 장면끼리 연결되며 영상 파일이 있으면 해당 장면에 사용할 수 있습니다.
수동 편집기의 기본 출력은 1080p이며 화면을 채우는 크롭을 사용합니다.
자동 편집에서 저장한 글꼴·자막 배경·외곽선 설정을 수동 편집에도 적용합니다.
기본 글꼴은 Pretendard Black입니다. 검정 자막 배경과 글자 외곽선은 각각 옵션으로 끌 수 있습니다.
이 옵션은 자막을 위한 것입니다. 영상 양옆의 빈 검정 공간은 화면을 채우는 편집으로 제거합니다.
수동 편집기는 인증한 DINO 롱폼 화면에서 실행해야 사용할 수 있습니다.
음성은 본인 API 설정 또는 본인 PC에 설치한 로컬 음성 기능을 선택하세요.

6. 대본과 썸네일 기본 스타일
대본은 진행자가 근거를 직접 해석하는 말투로 작성하고, 반복되는 출처 소개를 줄입니다.
초반에는 질문의 핵심과 볼 이유를 제시하고, 중간에는 새로운 사례·비교·판단 기준을 이어갑니다.
출처와 근거 연결은 설명글과 작업 자료에 남기며 사실과 해석은 구분합니다.
롱폼 썸네일은 하단에 흰색·빨간색 두 줄을 배치하고 자연스러운 글자 비율과 얇은 검정 외곽선을 사용합니다.
썸네일에는 Pretendard Bold, 영상 자막과 상단 제목에는 Pretendard Black을 사용합니다.
완성 후 영상·썸네일·제목·설명글·태그를 확인하세요. 설명글과 태그는 함께 복사할 수 있습니다.

7. 기존 사용자 업데이트와 오류 확인
기존 프로그램을 종료하고 새 배포본 전체를 새 폴더에 풀어 실행하세요.
기존 인증, 개인 설정, 로컬 모델과 등록한 목소리는 해당 PC의 저장 위치에서 이어 사용합니다.
처음 사용하는 다른 PC에서는 그 사용자의 구독 인증과 계정/설치가 필요합니다.
실행 오류는 오류확인_실행.cmd 또는 logs 폴더로 확인하세요.
Codex에 도움을 요청할 때 프로그램 폴더와 오류 로그를 확인해 달라고 하면 됩니다.
API 키·구독 인증 파일·개인 음성·모델 캐시는 다른 사람에게 보낼 배포본에 넣지 마세요.
