03. ZIP 설치·구독 인증·업데이트

  1. 받은 ZIP을 새 폴더에 전체 압축 해제하세요. ZIP 내부에서 바로 실행하지 마세요.
  2. 기존 DINO 작업을 저장하고 기존 프로그램을 종료한 뒤 새 폴더의 00_실행.cmd를 실행하세요. 실행 파일과 연결보조·필수 프로그램 파일을 함께 보관하세요.
  3. 롱폼 또는 쇼츠를 선택하고 구독 결제에 사용한 이메일로 인증하세요.
  4. 화면의 구독 남은 기간과 만료일을 확인하세요. 본인의 유효한 구독이 있어야 제작 기능을 사용할 수 있습니다.
  5. 설정에서 아래 권장 조합을 저장하고 짧은 시험 제작을 하세요. 프로그램이 실제로 연 주소의 탭을 재사용하세요. 기존 작업 탭을 여러 개 열지 마세요.
업데이트를 위해 완전 초기화나 모델 삭제를 할 필요가 없습니다. 같은 PC·Windows 계정에서는 기존 보호 저장소의 인증·설정과 설치 모델·등록 목소리를 이어 사용합니다. 진행 중 작업은 기존 버전에서 마치고 새 제작부터 업데이트 버전을 사용하세요.

구독 만료 후 제작 기능은 차단됩니다. 로컬 기능을 선택해도 DINO 구독 인증은 필요합니다. 이미 저장한 완성 파일은 보관됩니다. 다른 PC에서는 그 사용자의 구독과 본인 계정 설정이 필요합니다.

04. Codex PC앱 설치·DINO 연결

OpenAI 공식 PC앱 설치 안내와 공식 시작 안내를 이용하세요. PC앱을 설치하고 본인 ChatGPT 계정으로 로그인한 다음, Codex에서 압축을 푼 DINO 폴더를 작업 폴더로 여세요. 앱 버전에 따라 통합 PC앱에서 Codex를 선택하는 방식으로 표시될 수 있습니다.

  1. DINO에서 자료 조사·대본 연결 → Codex · PC앱 대화로 조사·대본 요청을 선택하세요.
  2. 이미지 선택 → Codex · 이미지 생성 연결을 선택하세요. 썸네일도 Codex · 배경 생성 후 한글 합성을 고르세요.
  3. 주제를 입력하고 전체 제작을 시작하세요. DINO의 진행 상태·완성 파일에 준비된 Codex 요청문을 복사하세요.
  4. 이 DINO 폴더를 열어 둔 Codex 대화에 붙여 넣어 보내세요. 자료·대본 요청에 이어 이미지 요청도 해당 대화에서 처리합니다.
  5. Codex가 결과를 등록하면 DINO의 완료 개수가 올라갑니다. 첫 장면의 문장 대응·캐릭터·한글을 확인하고 잘못된 장면만 고치세요.
  6. 이미지 요청이 많거나 사용량 제한에 도달했다면 같은 작업의 요청 파일과 완료 상태를 유지해 이어가세요. 별도 새 작업을 중복 생성하지 마세요.

DINO가 Codex 대화를 직접 시작하거나 내장 이미지 도구를 외부에서 호출하는 방식은 아닙니다. 준비된 요청문을 실제 대화에 보내야 합니다. CLI를 직접 입력하는 대신 PC앱의 대화와 동봉 도우미를 사용하는 흐름입니다.

이미지 생성 기능을 사용할 수 있는 계정·대화 환경이 필요합니다. 앱만 설치하면 모든 계정에서 같은 기능·한도가 보장되는 것은 아닙니다. OpenAI 이미지 생성 안내를 참고하세요. 앱 권한과 사용량 정책은 본인 환경을 따릅니다.

권장 조합 전체를 Codex 자료·대본 / Codex 이미지·썸네일 / 로컬 음성 / 영상화 0장으로 선택했다면, Dropshot·Inworld 가입이나 별도 이미지 API 키를 먼저 넣을 필요가 없습니다. 다른 단계를 API로 선택했다면 그 단계의 계정은 필요합니다.

06. 내 목소리 녹음·등록·시험

  1. 조용한 곳에서 배경 음악 없이 본인의 목소리만 녹음하세요. 허용 길이는 5~45초, 권장은 10~20초입니다. 마이크 녹음은 40초에 자동 종료됩니다.
  2. 목소리 이름을 정하고 녹음에서 읽은 문장을 실제 낭독과 똑같이 입력하세요. 단어를 빼거나 다른 문장을 넣지 마세요.
  3. 마이크로 녹음 → 녹음 끝내기를 누르거나 기존 음성 파일을 불러오세요.
  4. 본인 목소리 확인란을 확인하고 이 목소리 등록을 누르세요. 등록한 목소리 듣기로 원본 녹음 상태를 확인하세요.
  5. 새로운 짧은 문장을 입력하고 Qwen으로 시험 생성하세요. 발음·잡음·반복·누락을 들어 보세요.
  6. 음성 생성 방식 → Qwen 로컬 · 내 목소리에서 등록한 목소리를 선택하고 음성 선택 저장을 누르세요. 제작 설정의 음성도 로컬로 선택됐는지 확인하세요.

등록한 목소리는 같은 PC에 저장됩니다. 매번 녹음할 필요가 없습니다. 다른 사람에게 배포할 ZIP에 개인 녹음과 목소리 프로필을 넣지 마세요. 사용할 권한이 있는 목소리만 등록하세요.

로컬 음성 PC 조건이 부족하면 먼저 PC 조건을 확인하세요. 그때 필요에 따라 Inworld 등 클라우드 음성을 선택할 수 있습니다. 처음부터 Inworld 유료 가입을 필수 단계로 안내하지 않습니다.

07. 첫 영상 제작: 짧게 완성해 보기

  1. 주제 또는 직접 대본을 넣고 언어·화풍·분량을 선택하세요. 처음에는 짧은 분량으로 세팅부터 확인하세요.
  2. 자료·대본과 이미지·썸네일은 Codex, 음성은 로컬, 영상화 장면 수는 0으로 설정하세요.
  3. 캐릭터가 필요한 경우 레퍼런스 이미지 넣기로 등록하세요. 얼굴·안경·수염·기본 의상은 유지하되 같은 장소·정면 구도만 반복하지 않도록 확인하세요.
  4. 전체 제작 후 표시되는 자료·대본 요청과 이미지 요청을 Codex 대화에 전달하세요.
  5. 장면별 완료 개수와 오류를 확인하세요. 실패한 장면은 해당 장면만 재생성하고 전체를 다시 시작하지 마세요.
  6. 음성·자막을 확인한 뒤 최종 편집하세요. 정지 장면의 기본 줌·팬, 부드러운 교차 전환과 자막 안전 영역을 확인하세요.
  7. 최종 MP4를 직접 재생하고 썸네일·제목·설명·출처·태그를 함께 확인하세요.

몰입형은 시청자에게 직접 말하는 공감 해설과 문장에 맞는 다양한 화면 구성을 뜻합니다. 모든 장면에 해설자를 넣거나 이름 있는 가상 인물의 긴 이야기를 기본으로 만드는 방식이 아닙니다. 목표 시간을 채우기 위한 반복은 피하고, 실제 길이는 생성된 음성을 기준으로 확인하세요.

10. KIE 키 발급·앞장면 영상화

  1. KIE API Key 관리에서 본인 계정으로 로그인하고 새 키를 발급하세요.
  2. 키를 DINO API 계정 → KIE API 키에 저장하세요. DINO 구독과 KIE 크레딧은 별도입니다.
  3. 영상화 연결에서 KIE API를 선택하세요. KIE 연결 점검 · 과금 없음으로 인증·잔액·시험 이미지 업로드·읽기를 확인하세요.
  4. 실제 움직이는 장면이 필요한 경우에만 영상화 장면 수를 직접 1장 이상 설정하세요. 예를 들어 3장으로 설정하면 앞 3장만 적용합니다.
  5. 선택한 모델과 크레딧을 확인한 뒤 최종 제작을 진행하세요. 나머지 장면은 정지 이미지와 기본 줌·팬·전환을 사용합니다.
KIE 키가 없으면 KIE 영상화는 0장입니다. 키를 저장해도 0장 설정이면 영상화를 하지 않습니다. 키가 있다는 이유만으로 유료 영상 생성이 켜지지 않습니다. 연결 점검 성공이 모든 모델·콘텐츠의 생성 성공을 보장하지는 않습니다.

현재 기본 KIE 영상 모델은 Bytedance V1 Pro Fast로 5초·720p를 요청합니다. 실제 결과 크기와 비용은 제공사가 반환한 파일과 생성 기록을 확인하세요. 오류 후 기존 작업 번호가 있으면 같은 작업을 조회하고, 접수 여부가 불확실하면 새 유료 요청을 반복하지 마세요. KIE 작업 기록을 먼저 확인하세요.

공식: 키 발급·인증 안내 · 모델 안내 · 동봉된 KIE 문제 해결 TXT

11. Dropshot MCP·Inworld는 선택 사항

Dropshot MCP를 쓰려면

  1. Codex의 플러그인 목록에서 Dropshot을 연결하고 본인 Dropshot 계정으로 인증하세요. 모델별 이용 조건·크레딧을 확인하세요.
  2. DINO의 영상화 연결을 Dropshot MCP로 선택하고 앞에서부터 영상화할 장면 수를 지정하세요.
  3. 음성 이후 준비된 Dropshot 요청문을 같은 DINO 폴더의 Codex 대화에 보내세요.
  4. 접수된 작업 번호가 있으면 같은 작업의 결과를 이어 받으세요. 실패를 이유로 다른 유료 제공사에 자동으로 새 요청을 보내지 않습니다.

처음에는 0장으로 기본 줌·팬과 전환을 확인한 뒤 필요할 때 추가하세요. Dropshot MCP에는 Dropshot 연결이 필요하며 KIE API 키와는 별도입니다. 동봉 Dropshot 영상 사용 안내를 참고하세요.

Inworld 음성을 쓰려면

  1. Inworld Portal에서 본인 계정으로 로그인하세요.
  2. Settings → API Keys에서 TTS 호출용 키를 발급하세요. 공식 안내의 Base64 자격 증명을 그대로 복사하고 다시 Base64 변환하지 마세요.
  3. 음성을 미리 듣고 사용할 Voice ID를 확인하세요. 다른 사용자의 Voice ID나 키를 복사해서 사용하지 마세요.
  4. DINO에서 음성 → 인월드 · Voice ID를 선택하고 Basic Key와 Voice ID를 각각 입력·저장하세요.
  5. 짧은 문장으로 시험하세요. 권한·잔액·선택한 음성 사용 권한을 확인하세요.

처음 사용자는 지원 PC에서 로컬 Qwen 음성을 먼저 권장합니다. 로컬 조건이 부족하거나 클라우드 음성이 필요할 때 Inworld를 선택하세요. Inworld 공식 TTS 시작 안내를 참고하세요. 제공사 화면과 요금은 변경될 수 있습니다.

12. 텔레그램 완성 알림: 처음부터 자세히

권장 설정은 본인 전용 봇 → 본인 개인 대화입니다. DINO는 완성 알림을 보내며, MP4 파일은 PC 완성 폴더에 저장합니다. 텔레그램 알림은 Codex 작업 예약이나 영상 자동 공개 기능을 뜻하지 않습니다.

① 텔레그램 설치·봇 발급

  1. 텔레그램 공식 앱을 설치하고 본인 계정으로 로그인하세요.
  2. 공식 @BotFather를 열고 시작하세요.
  3. /newbot을 보내고 표시 이름을 정하세요. 예: DINO 완성 알림.
  4. 영문 사용자 이름을 정하세요. 다른 봇과 중복되지 않으며 bot으로 끝나야 합니다. 예시는 my_dino_notice_bot이며 실제로 비어 있는 이름을 직접 정하세요.
  5. BotFather가 발급한 토큰 전체를 복사하세요. 토큰은 봇을 제어하는 자격 증명이며 DINO 구독 비밀번호나 Chat ID가 아닙니다.
  6. 방금 만든 새 봇의 대화방을 여세요. BotFather 대화방이 아닙니다. 시작 버튼 또는 /start를 보내고 개인 메시지 하나를 보내세요.

② DINO 설정·시험·켜기

  1. DINO 설정에서 완성·알림 영역의 텔레그램 완성 알림 · 롱폼을 찾으세요. 설정을 아래로 내려야 보일 수 있습니다. 쇼츠에서도 해당 모드의 설정을 확인하세요.
  2. 봇 토큰 붙여넣기 칸에 토큰을 넣고 아이디 찾기를 누르세요. 정상 형식의 토큰 입력 후 자동 조회될 수도 있습니다.
  3. 찾은 대화 목록에서 본인 개인 대화를 선택하세요. Chat ID는 텔레그램 사용자 이름과 다른 식별 번호이며 DINO가 찾아줍니다.
  4. 저장 & 테스트를 누르고 텔레그램에서 시험 알림을 확인하세요. 대화가 하나만 검색되면 자동 저장·시험이 진행될 수 있습니다.
  5. 알림 켜기를 체크하세요. 등록만 하고 체크하지 않으면 완료 알림이 꺼진 상태일 수 있습니다.
  6. 짧은 영상 한 편을 완성한 후 알림과 PC의 완성 파일을 함께 확인하세요. PC가 꺼졌거나 제작 프로그램이 종료되면 제작을 계속할 수 없습니다.

③ 연결이 안 될 때

증상확인 순서
토큰 형식·인증 오류BotFather의 발급 토큰 전체를 복사했는지, 앞뒤 공백과 줄바꿈이 없는지 확인하세요. 봇 사용자 이름을 토큰 칸에 넣지 마세요.
대화를 못 찾음새 봇에게 먼저 개인 메시지를 보내고 아이디 찾기를 다시 누르세요. BotFather에게만 메시지를 보낸 경우 새 봇의 대화가 아닙니다.
다른 앱과 충돌·409같은 봇 토큰을 쓰는 다른 프로그램이나 webhook이 있는지 확인하세요. 처음 사용자에게는 DINO 전용 새 봇이 편합니다. 다른 서비스의 webhook을 임의로 삭제하지 마세요.
시험 알림은 오지만 완성 알림이 없음현재 모드의 알림 켜기·저장 상태, 실제 최종 편집 완료 여부, PC 절전·인터넷 상태를 확인하세요.
봇 차단·대화 삭제차단을 해제하고 새 봇 대화에서 시작·메시지를 보낸 뒤 다시 조회·선택·저장하세요.
토큰이 노출됨BotFather에서 해당 봇의 토큰을 폐기·재발급하고 DINO에 새 토큰을 저장하세요.

④ 그룹·채널은 필요한 경우에만

먼저 개인 대화로 시험을 끝내세요. 그룹에 보내려면 본인이 관리하는 그룹에 봇을 추가하고 /start@봇사용자이름처럼 해당 봇을 대상으로 메시지를 보낸 뒤 DINO에서 그 대화를 찾아 선택하세요. 그룹 권한과 개인정보 설정에 따라 수신할 수 있는 메시지가 다릅니다. 채널은 게시 권한 등 추가 설정이 필요하며 목록 검색이 보장되지 않으므로 처음 설정은 개인 대화를 권장합니다.

공식 근거: 봇 토큰 발급 · 사용자 이름·봇 관리 · 대화 조회와 webhook 제약

13. 완성 파일·저장·재생성

오른쪽 진행 상태·완성 파일에서 제작 진행과 결과를 확인하세요. 좁은 화면에서는 설정 아래로 결과가 이어집니다. 최종 영상의 생성 완료와 다운로드 완료를 구분하고 실제 MP4를 재생하세요.

  • MP4: 최종 영상. 처음·중간·끝의 소리와 자막을 확인하세요.
  • SRT: 시간 정보가 있는 자막 파일.
  • 썸네일: 한글 제목의 가독성·비율·안전 영역을 확인하세요.
  • 제목·설명·출처·태그: 영상과 함께 보관하고 확인 후 사용하세요.

완성 폴더 열기 또는 다운로드에서 프로그램이 표시하는 실제 저장 위치를 확인하세요. 사용자 PC마다 설치·저장 경로가 다를 수 있으므로 특정 제작자 PC 경로로 고정하지 않습니다. 저장할 때 회차 번호와 제목을 붙인 폴더를 사용하면 중복 관리가 쉽습니다.

중지된 작업은 작업 보관함에서 같은 작업을 선택해 이어가세요. 완료한 장면은 보존하고 오류 장면만 복구하세요. 구독 만료·연결 제한·생성 제한으로 완성하지 못한 상태를 완료 영상으로 표시하지 않습니다.

14. 자주 막히는 부분

Codex에 요청했는데 DINO가 대기 중입니다

올바른 DINO 폴더를 연 대화인지, 현재 작업의 최신 요청문을 보냈는지 확인하세요. 자료·대본 요청과 이미지 요청이 별도로 준비될 수 있습니다. 이미지 도구를 사용할 수 있는 대화인지도 확인하세요.

로컬 모델이 설치됐는데 선택되지 않습니다

설정 → 내 PC 설치·목소리에서 설치 상태와 경로를 확인하세요. 다른 드라이브나 Windows 계정의 모델과 혼동하지 마세요. 기존 모델 폴더를 임의로 지우기 전에 경로와 시험 생성을 확인하세요.

음성이 오류이거나 말이 누락됩니다

원본 녹음의 잡음·배경 음악과 녹음 문장 일치를 확인하고 짧은 새 문장으로 시험하세요. 현재 선택한 목소리가 로컬인지 Inworld인지 확인하세요. 이미 완료한 음성을 보존하고 실패한 항목의 상태부터 확인하세요.

KIE 키가 있는데 영상화가 안 됩니다

영상화 연결이 KIE인지, 장면 수가 0보다 큰지, 키 저장과 연결 점검이 성공했는지 확인하세요. 0장은 생략하는 정상 설정입니다. 접수된 작업 번호가 있으면 기존 작업을 조회하세요.

한글 간판·얼굴·손이 틀립니다

짧은 정확한 한글 표기만 요청하고 이미지를 확인하세요. 장면별 핵심 대상과 행동에 맞게 해당 장면만 수정하세요. 참조 이미지를 써도 모든 세부 표현을 보장하지는 않습니다. 썸네일 제목은 프로그램의 한글 합성 결과도 확인하세요.

이전 버전과 새 버전이 동시에 실행됩니다

기존 작업을 저장하고 기존 DINO 프로그램을 종료한 뒤 새 버전을 실행하세요. 사이드의 기존 작업 탭을 재사용하고 중복 작업 탭은 닫으세요. 진행 중 작업을 끝내기 전에 강제로 프로그램을 종료하지 마세요.

구독 인증이 안 됩니다
