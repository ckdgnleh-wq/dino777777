이 폴더의 DINO 프로그램에서 로컬 이미지 생성과 로컬 음성을 사용하고 싶어.
내 PC의 Windows 버전, 그래픽카드와 VRAM, RAM, 디스크 여유 공간, 기존 DINO 로컬 설치를 먼저 확인해줘.
DINO의 로컬 기능 안내와 설치 목록을 읽고, 내 PC가 지원하는 기능만 DINO에 포함된 공식 설치 기능으로 설치해줘.
이미 설치된 모델, 정상 작동하는 실행 환경, 등록한 목소리, 인증 정보, 기존 작업은 보존하고 필요한 항목만 설치하거나 연결해줘.
설치 파일과 모델은 프로그램에서 지정한 공식 출처를 사용하고, API 키나 내 계정 정보는 채팅에 출력하지 마.
설치가 끝나면 DINO에서 연결 상태와 짧은 이미지·음성 시험 결과를 확인해줘.
PC 조건이 부족한 기능은 무리하게 설치하지 말고 어떤 조건이 부족한지 알려줘. 가능한 기능은 계속 진행해줘.
