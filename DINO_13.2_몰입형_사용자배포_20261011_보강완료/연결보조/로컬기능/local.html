DINO 13.2 몰입형 로컬 기능

1. 설치 가능 여부

Windows 10/11 64비트 · NVIDIA RTX 30 시리즈 이상(Compute 8.0+) · 드라이버 551.61 이상.
이미지: VRAM 8GB·메모리 32GB 이상, 권장 VRAM 12GB·메모리 64GB.
음성: VRAM 6GB·메모리 16GB 이상. 설치 후 시험 생성으로 실제 동작을 확인합니다.

사양 확인을 누르면 설치 버튼이 활성화됩니다.
모델설치 상태·조건설치

Z-Image·FLUX는 인코더와 이미지 실행 환경을 공유합니다. 설치 용량에는 모델·CUDA 실행 환경과 작업 여유 공간이 포함됩니다. 처음 설치할 때 인터넷 연결이 필요합니다.

모델 기능과 상업용 라이선스

Z-Image Turbo: 9단계 · 레퍼런스 미지원. FLUX.2 klein 4B FP8: 4단계 · 인물 레퍼런스 1장 지원. API와 같은 장면·화풍 프롬프트 경로를 사용합니다. 썸네일은 배경 이미지 생성 후 한글 흰색·빨간색 제목을 합성합니다.

모델 라이선스: Apache 2.0. Z-Image · FLUX 4B FP8 · Qwen 음성. 파일 재배포 시 동봉 라이선스를 확인하세요.

3. 내 목소리 녹음·등록

목소리는 한 번 등록하면 이 PC에 저장되며, 프로그램을 다시 실행하거나 완전 초기화를 눌러도 유지됩니다. 매번 녹음할 필요가 없습니다. 목소리를 바꾸거나 저장된 녹음을 삭제했을 때만 다시 등록하세요.

필요한 길이: 5~45초 · 권장 10~20초. 설치 후 조용한 곳에서 배경 음악 없이 본인 목소리만 자연스럽게 녹음하세요. 아래 문장을 읽거나 원하는 문장을 입력해 읽어도 됩니다. 읽은 문장을 실제 녹음과 똑같이 입력해야 합니다. 기존 음성 파일도 불러올 수 있습니다. 마이크 녹음은 40초에 자동으로 끝납니다.

녹음과 목소리 프로필은 이 PC의 설치 폴더에 저장됩니다. 녹음은 이미지·음성 서비스 제공사로 전송하지 않습니다. 긴 대본은 문단별로 낭독하고 실제 음성에 맞춰 SRT 자막 시간을 계산합니다.

4. 사용할 목소리 선택

이미지는 제작 화면의 첫 「이미지 선택」 메뉴에서 KIE / OpenRouter / 로컬 FLUX / 로컬 Z-Image를 바로 고릅니다. 설치된 로컬 모델만 선택할 수 있으며, 이 설정 화면에서 따로 적용할 필요는 없습니다.

로컬 이미지는 한 장씩 생성하고, 이미지 모델 메모리를 해제한 뒤 Qwen 음성을 생성합니다. 대본·자료 조사는 기존 API 설정을 사용합니다. 수동 편집기에서도 등록한 Qwen 목소리를 선택할 수 있습니다.
