DINO 13.2 몰입형 사용자버전 · 수동편집기 포함
작업 종료와 완전 초기화 안내

1. 현재 작업을 처음부터 다시 만들 때
   [완전 초기화]를 누르세요.
   현재 선택한 작업을 종료하고 보관함에서 제외한 뒤,
   기존 DINO와 실행 CMD를 닫고 새 작업 화면으로 다시 시작합니다.
   제외한 작업 때문에 같은 제목의 새 작업이 '이어하기'로 막히지 않습니다.

2. 보관함에 남은 특정 작업을 없애고 싶을 때
   [작업 보관함] 또는 [작업 보관함]을 여세요.
   해당 제목 옆 [작업 종료 · 보관함에서 제외]를 누르세요.
   현재 실행 중인 작업이라면 요청을 중지하고 프로그램을 다시 시작합니다.

3. 실수로 제외했다면
   보관함의 [제외한 작업 보기] → [보관함으로 복원]을 누르세요.
   복원만으로 생성 작업을 자동 실행하지 않습니다.

대본, 생성 이미지, 음성, 영상은 보존됩니다.
보관함 제외는 파일을 삭제해서 디스크 공간을 비우는 기능이 아닙니다.
완전 초기화는 현재 작업을 대상으로 하며 다른 보관 작업은 남습니다.
API 방식과 드롭샷 방식의 롱폼·쇼츠에 적용했습니다.
기존 수동편집기의 번호 매칭, MP4 우선 적용, 인월드 음성과 편집 기능을 포함합니다.

사용 방법
기존 프로그램과 CMD를 종료하고, ZIP 전체를 새 폴더에 풀어 00_실행.cmd를 실행하세요.
EXE만 따로 옮기지 마세요.
