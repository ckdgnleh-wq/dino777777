DINO 13.2 몰입형 사용자버전 · Codex 이미지 연결

V12와 별도 폴더에 압축을 풀고 00_실행.cmd로 실행하세요.
두 버전은 같은 프로그램 포트를 사용하므로 기존 DINO를 종료한 뒤 13.2 몰입형 을 켜세요.
손님은 기존 구독 인증, 관리자는 기존 관리자 비밀번호로 사용합니다.
설정은 13.2 몰입형 용으로 따로 저장합니다. 기존 V12 API 설정이 있으면 첫 실행 때 복사합니다.
이전 작업과 V12 ZIP은 변경하지 않습니다. 로컬 모델 설치와 등록한 목소리는 기존 경로에서 사용합니다.

사용 순서
1. 이미지 선택에서 [Codex · 이미지 생성 연결]을 선택합니다.
2. 평소처럼 제목 또는 대본을 넣고 [전체 제작]을 누릅니다.
   자료·대본·장면 프롬프트는 기존 설정대로 준비합니다.
3. [Codex 요청문 복사]가 활성화되면 눌러서, 이미지 생성 도구가 있는 Codex 대화에 붙여 넣어 보내세요.
   이 13.2 몰입형 폴더를 읽을 수 있는 같은 PC의 Codex 대화를 사용하세요.
4. Codex가 요청 파일을 읽고 내장 이미지 생성 도구로 한 장씩 만듭니다.
   생성 결과를 확인하고 동봉 도우미로 등록합니다. 사용자가 이미지를 일일이 옮길 필요는 없습니다.
5. 13.2 몰입형 은 현재 장면 요청과 결과가 맞는지 검사하여 받습니다.
   [완료 3/20]처럼 받은 이미지 수가 표시됩니다.
6. [음성·영상까지 자동]이 켜져 있고 선택한 음성이 준비되면,
   모든 이미지 완료 후 기존 음성·자막·편집으로 MP4를 만듭니다.
   13.2 몰입형 화면을 열어 두세요. 창을 닫았으면 작업 보관함에서 선택하여 이어 제작하세요.

중요한 연결 방식
13.2 몰입형 이 외부에서 Codex 대화의 내장 이미지 도구를 직접 호출하거나 대화를 자동 시작하는 방식은 아닙니다.
현재 영상마다 요청문을 Codex에 한 번 전달해야 합니다. 이미지가 많은 영상은 여러 번 이어 생성해야 할 수 있습니다.
이 대화의 이미지 도구 사용 가능 여부와 생성 한도는 Codex 환경·계정 사용량에 따릅니다.
별도 OpenAI 이미지 API를 연결하거나 결제하지 않습니다. 사용할 수 없으면 자동으로 다른 유료 이미지 API를 호출하지 않습니다.
자료 조사·대본·음성 등 기존 API를 선택한 기능의 사용 비용은 해당 제공사에서 발생합니다.
Codex 대화에서 DINO 폴더와 요청 파일에 접근할 수 없으면 결과 연결을 사용할 수 없습니다.

이미지와 썸네일
기존 API와 같은 장면 프롬프트 형식을 사용합니다. 상황·맥락에 맞는 피사체를 만들고, 인물을 무조건 넣지 않습니다.
가로 롱폼은 16:9, 쇼츠 본문은 9:16로 요청합니다.
레퍼런스가 필요한 장면만 현재 작업의 첨부 이미지를 넘깁니다.
롱폼 썸네일은 글자 없는 배경 이미지를 받은 뒤 기존 흰색·빨간색 한글 제목 합성기를 사용합니다.
생성 모델 특성상 얼굴·간판·문자와 세부 장면이 매번 정확하다고 보장할 수는 없습니다. 완성된 이미지를 확인하세요.

중지·초기화·재생성
[중지]하면 이미지 결과 대기를 멈춥니다. 이미 완성한 파일은 보관합니다.
[완전 초기화]는 현재 작업을 보관함에서 제외합니다. 해당 작업으로 뒤늦은 결과가 와도 진행하지 않습니다.
장면을 재요청하면 새 요청 ID를 사용하므로 이전 장면 결과를 현재 장면으로 받지 않습니다.
다시 진행하려면 13.2 몰입형 에서 이어 제작을 선택한 뒤 새 요청문을 Codex에 보내세요.
이미 완료한 장면은 다시 생성하지 않습니다.

Codex가 사용하는 동봉 도우미
파일: 연결보조\Codex이미지\codex_image_worker.py
Python 표준 라이브러리만 필요합니다. Codex의 Python 실행 환경으로 사용할 수 있습니다.
사용자에게 터미널 명령을 요구하지 않습니다. 복사한 요청문을 받은 Codex가 수행합니다.
명령 순서: --manifest <요청 파일> status → next → 이미지 생성 → complete --id <id> --source <실제 생성 이미지 경로>
Codex는 요청마다 next를 다시 실행하고, 남은 요청이 없을 때까지 한 장씩 등록합니다.
이미지 생성 도구가 없는 Codex 환경이면 사용할 수 없다고 알리고 멈춥니다.

기존 기능
API·드롭샷 방식, 직접 대본 입력, 연속 제작, 로컬 설치·내 목소리,
롱폼 수동 편집기, 문장/번호 매칭, MP4 우선 사용, 자막, 움직임 선택을 유지합니다.
수동 편집기는 롱폼 전용입니다. 기존 이미지나 영상 파일을 직접 넣어도 사용할 수 있습니다.
쇼츠의 기존 최대 2분 50초 완성 길이 제한을 유지합니다.

검사한 범위
API·드롭샷 실제 실행 모듈에서 장면 요청/이미지 수신/중지/초기화/자동 이어 제작을 확인했습니다.
브라우저 화면에서 Codex 선택, 요청문/완료 개수, API 선택 복귀를 검사했습니다.
실제 Codex 생성 이미지로 30fps MP4, 한글 자막과 오디오 적용을 확인했습니다.
영상 검사 오디오는 시험 음원입니다. 이번 검사에서 새 유료 음성 API 호출은 하지 않았습니다.
구독·관리자 인증, API 키, 사용자 작업, 개인 목소리 녹음과 모델 파일은 배포 ZIP에 넣지 않았습니다.
