DINO 13.2 몰입형 · KIE 앞장면 영상화 점검

1. API 계정에 본인의 KIE 키를 저장하세요. Bearer 접두어를 함께 복사한 경우 키 부분만 사용하도록 정리합니다.
2. 영상화 연결을 KIE API로 선택하고 장면 수를 직접 지정하세요. 0이면 키가 있어도 영상화하지 않습니다.
3. 영상화 설정의 'KIE 연결 점검 · 과금 없음'을 누르세요. 저장한 키의 인증·잔액·시험 이미지 업로드·결과 읽기를 확인합니다.
   이 버튼은 영상 생성 요청을 보내지 않습니다. 모델 생성 권한과 콘텐츠 허용 여부까지 보장하지는 않습니다.
4. 이미지 생성이 끝나면 최종 제작에서 선택한 앞 N장만 KIE로 영상화합니다. 기본 모델은 Bytedance V1 Pro Fast, 5초, 720p 요청입니다.
   실제 결과 크기는 제공사가 반환한 파일에 따릅니다.

키 오류: 새 키를 다시 저장하세요. 인증과 DINO 구독 결제, KIE 크레딧은 별도입니다.
잔액 부족: KIE 크레딧 잔액을 확인하세요.
업로드 또는 결과 읽기 오류: 해당 단계의 서버 연결, 방화벽·프록시·DNS 설정을 확인하세요. 다른 사용자 PC의 원인은 각 오류 기록으로 확인해야 합니다.
작업 조회 404/422: 원래 접수한 KIE 계정의 키와 작업 번호를 확인하세요. 기존 번호를 보관하며 자동으로 새 유료 요청을 보내지 않습니다.
접수 응답이 끊겨 taskId를 받지 못함: 중복 과금을 피하기 위해 멈춥니다. https://kie.ai/logs 에서 이미 접수됐는지 확인한 뒤 진행하세요.
taskId를 받은 뒤의 조회·다운로드 오류: 기존 작업 번호/결과를 사용하여 이어 확인합니다.
문제 보고 시 진단 파일의 video_states에서 오류 장면·상태·작업 번호 존재 여부를 확인할 수 있습니다. API 키를 타인에게 보내지 마세요.

검증: 제작자 PC의 저장된 KIE 계정에서 무과금 점검과 실제 5초 영상 생성·다운로드 성공, 16크레딧. 모든 고객 계정·네트워크의 성공을 뜻하지 않습니다.
